## Exceptions: used in the project, but not shown exactly like this in the course
These are the places where the project goes a step beyond what the notebooks show. Say so if you are asked.

| what | what the course shows instead |
|---|---|
| `.randint()`, `.shuffle()` and `.random()` called on a `RandomState` | `RandomState` with `.choice()` and `.uniform()` (M1_SML_intro_2025.ipynb); `randint` and `shuffle` appear in other notebooks, but not on a `RandomState` |
| `timedelta(hours=..., minutes=...)` | `timedelta` is used in config.py and generate_dashboard.py, not with these parameters |
| `.month` on a date | `.year` and `.day` style attributes; `.month` is not shown |
| `parse_dates=` in `read_csv` | one notebook (EDA_dataviz_application_Py.ipynb) |
| `DataFrame.to_csv` | one notebook (M2_NLP_TopicModelBert.ipynb) |
| `os.path.join` | one notebook (M3_2_Transformermodels_NLU_Applications_SBERT_v1.ipynb) |

The pipeline rules, the bias test and the drift test are the project's own work. The course
provides the tools, not this analysis.
